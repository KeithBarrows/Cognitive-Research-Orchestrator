# User Story 05 — Router Hands Out the Resolver

**Status:** Not started

**Story:** As the CRO developer, I want the Gryphon router to give the resolver's address to devices, so every device uses it without manual setup.

**Done when:** A freshly joined device receives the laptop's resolver address instead of the ISP's.

**Notes:** The router points at the laptop's dnsmasq, not at 1.1.1.1 or 9.9.9.9 directly. Changing the router's DNS affects every device in the house, so show Keith the exact change before making it.
